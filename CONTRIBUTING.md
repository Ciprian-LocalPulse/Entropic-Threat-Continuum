# Contributing — Errata, Discussion, and Collaboration

Copyright (c) 2024 Ciprian Stefan Plesca. Released under the MIT License.

This is a **read-only academic repository** — the dissertation text itself is
not open to contributions. However, the scholarly community's engagement with
this work is welcomed and encouraged in the forms described below.

---

## What This Repository Accepts

### 1. Errata Reports
Errors in the dissertation text — typographical, mathematical, or factual —
may be reported by opening a GitHub Issue with the tag `[errata]`.

Please include:
- Chapter and section number
- Page number (if applicable)
- A clear description of the error
- (Optional) A suggested correction

Verified errata will be logged in [`docs/ERRATA.md`](./docs/ERRATA.md) and,
where substantive, will be addressed in future revised editions.

### 2. Formal Comments and Scholarly Discussion
Academic commentary, questions, extensions, or critiques of the theoretical
framework — including the Dark Topology Conjecture, the Adversarial Entropy
Gradient, and the Plesca Taxonomy — are welcome via GitHub Issues tagged
`[discussion]`.

The author reads all substantive academic commentary and will respond where
possible. High-quality discussion threads may be summarized and referenced in
future work.

### 3. Extensions to the Simulation Code
The simulation code in `src/simulation/` is provided for reproducibility.
If you have implemented extensions, tested the code on new configurations, or
identified bugs, please open a Pull Request with:
- A clear description of the change
- Evidence (output, tests) that the change is correct
- Full attribution if the extension builds on other published work

Pull Requests to the simulation code will be reviewed by the author.
Accepted contributions will be acknowledged in the repository and in
associated publications.

### 4. Permissions Requests
See [`LICENSE`](./LICENSE) for permitted uses. To request permission for uses
not already permitted, open an Issue tagged `[permissions-request]`.

---

## What This Repository Does NOT Accept

- Pull Requests modifying the dissertation text (Chapters, Parts, Abstract,
  Bibliography, or Appendices)
- Requests to relicense this work under open-source or Creative Commons terms
- Automated or bulk submissions of any kind
- Contributions that introduce content unrelated to the dissertation's scope

---

## Code of Conduct

All participants in Issues and Pull Requests are expected to engage with
scholarly courtesy and good faith. See [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md).

---

## Citation Requirement for All Extensions

Any work — including code, papers, or datasets — that builds upon, extends,
or applies frameworks from this dissertation **must cite the dissertation**
in full. See [`CITATION.cff`](./CITATION.cff) and [`citation/bibtex.bib`](./citation/bibtex.bib).
