# Errata

This file tracks known corrections, clarifications, and repository-level deviations from the dissertation text.

## Repository 1.1.0

- The repository is distributed under the MIT License. Older repository text described an all-rights-reserved posture; the current repository metadata supersedes that text for this code and documentation package.
- The machine-readable taxonomy file is a structured research artifact and includes representative primitive entries plus metadata declaring the complete taxonomy count.
- Simulation modules are academic models. Their outputs should be interpreted as exploratory evidence, not operational security guarantees.

## Reporting Errata

Open a GitHub issue with:

- the affected file, chapter, section, or line;
- the exact current wording or behavior;
- the proposed correction;
- supporting references where appropriate.
