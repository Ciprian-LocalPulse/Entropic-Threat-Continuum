# Roadmap

## Research-Grade Completeness

- Add calibrated empirical datasets for each ETC axis.
- Expand the taxonomy JSON from representative entries to a fully enumerated 847-primitive release.
- Add uncertainty intervals to all AEG, TDF, TSI, and DTC outputs.
- Add reproducible experiment manifests for every dissertation figure and table.

## Engineering

- Publish packaged releases to GitHub Releases.
- Add CI for tests, notebooks, taxonomy validation, and figure generation.
- Add type-checking and linting once the public API stabilizes.
- Add a formal JSON Schema for taxonomy artifacts.

## Documentation

- Add worked examples for enterprise security posture scoring.
- Add crosswalks to MITRE ATT&CK, STRIDE, DREAD, CVSS, and NIST CSF.
- Add an academic review guide for researchers extending the ETC framework.
